# Security

TrayTrim reads files other people made (CC packages, tray files, zips someone sent you), so a
damaged or hostile file shouldn't be able to crash it, fill your disk or write outside the
folders it uses.

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately on GitHub instead:
**Security > Report a vulnerability** on <https://github.com/stixez/TrayTrim>. Include the steps
or a small file that shows it, and which version you use (Settings > About).

TrayTrim is a one-person project, so an answer can take a few days. Fixes go into the next
release, and the report is credited unless you'd rather it wasn't.

## Supported versions

Only the latest release gets fixes. The app tells you when a newer one is out.
